# 账号导入、导出与加密同步

支持应用中已保存的 Claude Code、Codex、Antigravity 和 Grok 备用账号。导出不扫描其他应用的凭证目录，也不包含 GitHub 同步登录。

## 本地备份和迁移

1. 在“实时配额 → 账号”或“设置 → 常规偏好 → 管理账号”中打开账号管理。
2. 点击“导出账号”，选择 `.aumaccounts` 文件，输入并确认至少 10 个字符的口令。
3. 在另一台设备启用账号切换，点击“导入账号”，选择文件并输入口令。
4. 查看解密后的账号预览，点击“导入备用账号”确认。

导入只增加缺失的备用账号，已有账号的凭证保持不变，当前 Agent 登录也不会切换。手动导入可恢复之前在本机删除的备用账号。系统文件选择框支持保存位置和覆盖确认。备份中的 Antigravity 凭证会转换为目标平台的存储形状。

文件使用 AES-256-GCM 加密并验证完整性，PBKDF2-SHA256（600,000 轮、独立随机盐）从口令派生密钥，每次导出使用新的随机 nonce。口令不写入文件、配置或日志。忘记口令后无法恢复。当前文件格式为版本 1，最多 512 个账号，密文文件上限 16 MiB。

## 跨设备账号同步

在“设置 → 多设备同步”中登录 GitHub，然后开启“账号同步”，输入同步密码即可。各设备使用同一密码。账号同步依赖账号切换：账号切换尚未开启时，设置对话框会显示“同时开启账号切换（账号同步需要）”勾选框，勾选后才能开始同步；首次设置与重新输入密码分别使用“设置账号同步”和“解锁账号同步”标题。

“在此设备记住密码”默认选中，密码保存到 Windows 凭据管理器、macOS 钥匙串或 Linux 系统凭据库。重启后自动恢复同步，不再要求每次解锁。系统凭据库不可用或未勾选记住时，下次启动再输入密码；密码不会明文写入配置文件或发送到服务器。

同步状态在两处可见：设置页的账号同步区块，以及账号管理对话框顶部的状态行（状态点、已同步账号数、设备数、相对时间，悬停显示完整日期，附“立即同步”）。未开启同步时，账号管理对话框显示一条指向设置的提示。侧栏的“用量同步”行只反映用量数据同步，与账号同步互不影响。账号新增、改名和删除后立即触发同步；应用运行期间每分钟左右自动同步一次。

### 更换同步密码

同步已开启时，“同步密码设置”打开的是“更改同步密码”：输入新密码（需二次确认）即完成本机更换——本机快照立即用新密码重新封存，记住的密码一并更新。其他设备下次同步时会提示“N 台设备的快照无法用当前密码解开（可能仍在使用旧密码）”，在那些设备上输入新密码后整个更换即完成；完成之前，新旧密码封存的快照互相无法读取，但各设备自己的数据不受影响。全部快照都无法解开时仍视为密码输入错误，不会上传或导入任何内容。已彻底离线的设备会一直留在提示里，其旧快照对新密码永久不可读——这是端到端加密的固有属性：换密码是换锁，不是找回。

错误按类型给出中英文提示：网络与超时类错误保留已输入的密码，并说明稍后会自动重试；密码不正确时才要求重新输入，此时若清除了本机记住的密码会明确说明；服务器问题、设备数超限等各有对应文案，已知错误原文以小字附在提示下方便于报障。关闭“账号同步”开关会先弹出确认：本设备停止向其他设备同步账号更改，并删除本机记住的密码；已保存的账号不受影响。

### 账号变化怎样同步

- 新增账号会出现在其他设备。没有邮箱 / accountUuid / sub 等稳定身份的凭证只留在本机，不进入同步，避免 token 刷新被当成新账号。
- 改名和更新的备用凭证会同步；名称修改与凭证刷新分别比较修改时间，不相互覆盖。凭证时间只在文档字节变化时前进，单纯改文件 mtime 不会让旧 token 赢过远端。
- 缺席不是删除：本地有、并集没有、且没有删除记录时，当作新账号合并上去，不会因为某台设备还没见过它就删掉。
- 删除保存的账号会同步到其他设备。删除记录随密文一同同步，防止离线设备再次上线后把旧账号加回来。用户再次登录或导入同一身份时，新的凭证时间赢过旧删除记录，账号会保留。
- 同步不会写入 Agent 当前的登录存储。正在使用的账号不会被远端强行替换或删除；切换离开该账号后，待处理变化会继续同步。相关情况只在详情中解释。
- “移除全部账号”的确认会说明删除将同步到其他设备。普通配额刷新不会自动重新捕获已经删除的账号；需要恢复时，可重新登录、捕获当前账号或手动导入备份。

加密文件导入仍然先预览再确认，用于主动恢复缺失的账号；同步则持续处理新增、修改和删除。两者使用同一套加密，不新增独立协议或迁移流程。

## 服务端与诊断

客户端使用现有经过 GitHub 认证的账号对象存储，服务端只持有加密内容，继续按既有租户和存储配额隔离。不会把账号凭证写入用量数据。账号同步仍保持端到端密码加密，不依赖服务器持有密钥。关闭账号同步会删除本设备在服务器上的 `accounts-v1-*` 快照；无法解开的快照和其他设备的快照也可由同一 GitHub 租户主动删除。用量对象仍不可 DELETE，以免打穿 CAS 清单。

诊断日志只记录阶段、错误分类和数量。Windows 路径为 `%LOCALAPPDATA%\devin-usage-metrics\sync.log`。不会记录密码、授权 URL、授权码、邮箱、Token 或凭证正文。
