# omp agent importer

Added `model.Omp` ("omp") as the eleventh agent.

## Decisions

- **Schema shared with pi.** `~/.omp/agent/sessions/**/*.jsonl` uses the same
  record family as pi: `session` (v3), `model_change`,
  `thinking_level_change`, `title`, `title_change`, `message`, `custom`.
  The `omp()` parser mirrors `pi()` usage fields
  (`usage.input/output/cacheRead/cacheWrite/cost.total`).
- **Session id falls back to the filename.** omp transcripts are named
  `<createdAt>_<session-id>.jsonl` and a `{"type":"title"}` record can
  precede the `session` record, so `newFileParser` takes the UUID suffix
  after the last `_` to avoid an orphan file-id session.
- **Titles.** `session.title`, `title`, `title_change` and the first user
  `message` all feed `Session.Title`; explicit title records win.
- **Dedup by responseId.** `message.responseId` (fallback: record `id`)
  becomes `DedupKey`, deduped per session. Forked sessions that copy a
  parent prefix under a new session id still count separately — pi parity.
- **`ttft`/`duration`** on assistant messages map to `TTFTMs`/`TotalTimeMs`;
  pi does not populate these.
- **`model_usage` records count too.** `find`/`auto-thinking`/`judge` calls
  (e.g. `typesafe/jev-latest`) log usage outside the `message` stream; each
  becomes a turn with `ContextStream = "purpose/<purpose>"` and
  `DedupKey` = record `id`.
- **`thinking_level_change.thinkingLevel`** maps to `AgentMode`, like pi.
- **Skills only, no MCP target.** omp loads `~/.agents/skills` (inherited,
  like pi/codex) and gets a dedicated `~/.omp/agent/skills` column; no omp
  MCP config file was found in `~/.omp` so no MCP target is declared.
- **No Rust counterpart.** `src/` never imported omp; excluded from the
  migration differential on purpose.
- Verified against real `~/.omp` history: `go run . --cli --agent omp`
  produces sessions, models (`devin/swe-2`, `opencode-go/deepseek-v4-flash`),
  cache reads and recorded costs.
